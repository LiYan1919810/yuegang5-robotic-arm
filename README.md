# robotic-arm

机械臂算法控制开源项目。实现基于 Arduino 的机械臂基础运动控制、上位机串口指令交互、多舵机协同控制、自动夹取任务，以及 ESP8266 按键遥控与动作录制/回放。项目内含一个开源 Skill（`skills/robotic-arm/`），为团队协作开发提供统一的目录规范、协作流程、版本管理与开发记录约定。

## 项目功能需求

### 一、机械臂核心基础功能

- 各关节舵机的独立移动控制；
- 通过摇杆对机械臂进行实时操控。

### 二、上位机串口通信与指令响应

上位机（电脑）与机械臂（Arduino）通过串口建立通信，接收单字符指令并即时响应：

| 指令 | 功能 |
|------|------|
| `O` | 机械臂爪子张开 |
| `S` | 机械臂爪子关闭 |
| `H` | 提升机械臂整体运行速度 |
| `L` | 降低机械臂整体运行速度 |

### 三、多舵机协同控制

- 上位机发送格式为 `x(角度),y(角度),z(角度)` 的指令，示例：`x10,y30,z20`；
- 机械臂解析指令后，控制对应 x、y、z 编号的舵机，分别输出对应角度的 PWM 占空比，即**单条指令同步控制三个舵机**；
- x、y、z 舵机与具体关节的对应关系由团队自行定义。

### 四、自动夹取任务（需联合机械方向协作）

上位机发送 `A`、`B` 或 `C`，机械臂自动完成对应动作：

- `A`：夹取物体 A 并放置到指定位置；
- `B`：夹取物体 B 并放置到对应位置；
- `C`：夹取物体 C 并放置到对应位置。

三个物体的初始位置与放置位置可自定义，但要求各物体在 x 与 y 方向上有明显位移，且三个放置位置明显不同。

### 五、ESP8266 按键遥控（需联合硬件方向协作）

借助一块 ESP8266 开发板与 Arduino 建立串口通信，整体逻辑为：**ESP8266 捕获并解析 4 个按键输入**（具体引脚配置需询问硬件方向的同学），将控制指令经串口发送至 Arduino；Arduino 接收指令后驱动机械臂执行对应动作。

| 按键 | 功能 | 说明 |
|------|------|------|
| 按键 1（循环执行） | 循环触发夹取任务 | 首次按下夹取物体 A 并放置到指定位置；第二次按下切换为夹取 B；后续按下按 A → B → C 逻辑依次循环，完成三个物体的夹取与放置 |
| 按键 2（录制） | 动作录制模式 | 首次按下启动录制，人工通过摇杆操控机械臂，完成一段时长 **大于 10 秒** 且能体现明显位移的动作；第二次按下结束录制并保存动作数据 |
| 按键 3（播放） | 动作回放 | 按下后自动调取上一次录制的动作数据，完整复现 |
| 按键 4（回中） | 回归初始位置 | 按下后机械臂回到初始状态位置 |

## 开发协作（robotic-arm Skill）

本项目的算法控制部分通过 `skills/robotic-arm/` Skill 进行团队协作开发。该 Skill 约定：

- **统一模块目录**：`robotic-arm/src`（kinematics / trajectory / control）、`robotic-arm/tests`、`robotic-arm/docs`；
- **开发记录**：每次会话必须追加 `docs/DEVLOG.md`（日期、贡献者、完成项、决策、下一步），版本里程碑更新 `docs/CHANGELOG.md`；
- **版本管理**：语义化版本号（MAJOR.MINOR.PATCH）；新模块或接口变更创建 `feature/`、`fix/`、`experiment/` 分支，测试通过后合并回 `main`。
