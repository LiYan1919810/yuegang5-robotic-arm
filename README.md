# yuegang5-robotic-arm

基于 Arduino 的机械臂算法控制开源项目：从「直接给定舵机角度」到「给定笛卡尔坐标 (x, y, z)」，实现串口指令交互、多舵机协同、正逆运动学解算、直线插值轨迹、动作录制 / 回放与五点示教。

当前版本：**v0.4.0**

## 功能概览

| 模块 | 说明 |
|------|------|
| 摇杆操控 | 双摇杆实时控制四个舵机，带死区、限速与行程保护 |
| 串口指令 | 夹爪开合、动作组、坐标 / 角度设置、速度调节、模式切换 |
| 正逆运动学 | 坐标 → 关节角（余弦定理解析解）、关节角 → 爪尖坐标 |
| 直线插值 | 误差累积等比例插值，让爪尖沿近似直线运动 |
| 动作录制 / 回放 | 定时采样 + 阈值抽帧，最多 50 帧 |
| 五点示教 | 记录 5 个坐标点，逐点走直线复现，可夹笔在纸面画图 |

## 硬件与引脚

| 部件 | 引脚 | 说明 |
|------|------|------|
| 夹爪 Claw | D6 | 开合夹爪 |
| 右臂 Right | D7 | 肩关节（大臂） |
| 左臂 Left | D8 | 肘关节（小臂） |
| 底座 Middle | D9 | 底座回转 |
| 按键 1–4 | D10–D13 | `INPUT_PULLUP`，低电平有效 |
| 摇杆 1 X / Y | A0 / A1 | Middle / Left |
| 摇杆 2 X / Y | A2 / A3 | Right / Claw |
| 摇杆按键 | A4 | `INPUT_PULLUP`，触发动作组 A |

主控为 Arduino Uno，舵机使用 `Servo` 库，串口波特率 **9600**。

## 串口指令

每行一条指令，以 `\n` / `\r` 结束。

| 指令 | 功能 |
|------|------|
| `O` | 张开夹爪 |
| `S` | 闭合夹爪 |
| `H` | `TURN_INTERVAL += 5`（间隔变大 → 变慢） |
| `L` | `TURN_INTERVAL -= 5`（间隔变小 → 变快） |
| `A` / `B` / `C` | 执行动作组 A / B / C（夹取放置） |
| `3` | 直线运动：`(100,0,50)` → 串联至 `(150,0,50)` |
| `2` | 直线运动至 `(120,50,50)` |
| `V` | 直线运动至 `(150,40,50)` 并串联后续轨迹 |
| `4` | 等同按下按键 1 |
| `5` | 画图 / 直线任务暂停 / 继续 |
| `7` | 切换为普通帧录制模式 |
| `8` | 切换为五点示教模式 |
| `0` | 查询当前爪尖坐标（正解） |
| `G x,y,z` | 直接逆解到坐标并驱动（调试用） |
| `x90,y50,z45` | 直接设置 Middle / Right / Left 舵机角度 |

> 说明：`H` / `L` 当前实现为调整 `TURN_INTERVAL`，因此 `H` 实际会变慢、`L` 会变快，与「H 加速 / L 减速」的原始需求语义相反，尚未修正。

## 按键与摇杆

| 按键 | 普通模式 | 示教模式 |
|------|----------|----------|
| 按键 1 | 画图任务进行中 = 暂停 / 继续；空闲 = 播放动作 A → B → C（按一次播放一次） | 同左 |
| 按键 2 | 录制开始 / 结束；播放中 = 暂停 / 继续 | 开始 / 结束示教；播放中 = 暂停 / 继续 |
| 按键 3 | 播放录制的动作帧；播放中 = 停止 | 录制中 = 打点；非录制 = 播放示教轨迹 / 停止 |
| 按键 4 | 回中：清空队列、停止直线与示教、回归初始位 | 同左 |

摇杆在动作队列执行或直线插值期间自动暂停输入，避免与轨迹任务争抢舵机。

## 运动学与轨迹

几何参数（`yaogan.ino` 顶部常量）：

| 参数 | 值 | 含义 |
|------|-----|------|
| `ARM_L1` | 80 mm | 大臂长度 |
| `ARM_L2` | 80 mm | 小臂长度 |
| `HEIGHT` | 50 mm | 底座轴到肩关节高度 |
| `CLAW_LEN` | 50 mm | 爪长（保持水平） |

- 坐标系：`x` / `y` 为水平面，`z` 为离地高度；底座回转角 φ 从 **+y 轴**量起（`atan2(x, y)`）。
- 逆解：`R = r - CLAW_LEN`，`D = √(R² + zArm²)`，由余弦定理求 `θ1`（大臂）、`θ2`（小臂），含可达性与行程校验。
- 关节角 → 舵机值：零点标定 `MIDDLE_ZERO=100`、`LEFT_ZERO=110`、`RIGHT_ZERO=145`，配合方向系数 `MIDDLE_DIR=+1`、`RIGHT_DIR=-1`、`LEFT_DIR=+1`。
- 直线插值：起点终点各逆解一次，按最大舵机增量确定步数，三个舵机等比例步进、够 ±1° 才转动。

## 原始需求

### 一、机械臂核心基础功能

- 各关节舵机的独立移动控制；
- 通过摇杆对机械臂进行实时操控。

### 二、上位机串口通信与指令响应

上位机（电脑）与机械臂（Arduino）通过串口建立通信，接收单字符指令并即时响应：`O` 张开夹爪、`S` 闭合夹爪、`H` 提升速度、`L` 降低速度。

### 三、多舵机协同控制

- 上位机发送格式为 `x(角度),y(角度),z(角度)` 的指令，示例：`x10,y30,z20`；
- 机械臂解析指令后，控制对应 x、y、z 编号的舵机，分别输出对应角度的 PWM 占空比，即**单条指令同步控制三个舵机**。

### 四、自动夹取任务

上位机发送 `A`、`B` 或 `C`，机械臂自动完成对应动作：夹取物体 A / B / C 并放置到指定位置。

### 五、ESP8266 按键遥控

借助 ESP8266 开发板与 Arduino 建立串口通信：ESP8266 捕获并解析 4 个按键输入，将控制指令经串口发送至 Arduino，由 Arduino 驱动机械臂执行对应动作。

| 按键 | 功能 | 说明 |
|------|------|------|
| 按键 1 | 循环触发夹取任务 | 按 A → B → C 依次切换，完成三个物体的夹取与放置 |
| 按键 2 | 动作录制模式 | 首次按下启动录制，摇杆操控机械臂完成一段动作；再次按下结束并保存 |
| 按键 3 | 动作回放 | 按下后调取上一次录制的动作数据，完整复现 |
| 按键 4 | 回归初始位置 | 按下后机械臂回到初始状态 |

## 快速开始

1. 用 Arduino IDE 打开 `yaogan/yaogan.ino`（或 `3126000394mearm/3126000394mearm.ino`）；
2. 选择开发板 **Arduino Uno** 与对应串口；
3. 编译上传（需 `Servo` 库，IDE 自带）；
4. 打开串口监视器，波特率设为 **9600**，行结束符选「换行」；
5. 输入 `0` 查询当前坐标，输入 `G 120,0,60` 让爪尖移动到指定位置。

## 开发协作（robotic-arm Skill）

本项目的算法控制部分通过 `skills/robotic-arm/` Skill 进行团队协作开发。该 Skill 约定：

- **统一模块目录**：`robotic-arm/src`（kinematics / trajectory / control）、`robotic-arm/tests`、`robotic-arm/docs`；
- **开发记录**：每次会话必须追加 `docs/DEVLOG.md`（日期、贡献者、完成项、决策、下一步），版本里程碑更新 `docs/CHANGELOG.md`；
- **版本管理**：语义化版本号（MAJOR.MINOR.PATCH）；新模块或接口变更创建 `feature/`、`fix/`、`experiment/` 分支，测试通过后合并回 `main`。
