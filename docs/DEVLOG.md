## 2026-09-30 — LiYan1919810 — 非阻塞舵机控制重构与按键遥控

- Done:
  - 定位并修复新增按钮功能后机械臂「一推就飞」的异常，根因为按键状态检测函数存在漏洞导致电平乱跳，修复后摇杆功能恢复正常；
  - 排查按键 1 按下后机械臂乱跳的问题，确认为动作函数依赖 `delay()` 导致的阻塞隐患；
  - 将 `turn()` / `Action()` 重构为基于 `millis()` 的非阻塞实现，新增 `actionTick()` 推进函数与 `actionQueue` 动作队列（`actionPhase` + 队列计数）实现动作排队执行；
  - 按键检测改为掩码式多键扫描 `updateButton()`，同时返回多路按键状态；
  - 在 `loop()` 中依据按键状态切换循环模式（`repeatMode`），完成按键 1 循环夹取与按键 4 随时回中功能。
- Decision: 采用「动作队列 + 节拍推进」的非阻塞状态机取代 `delay()` 阻塞式舵机控制，从根本上规避主循环阻塞；动作执行期间暂停摇杆输入，避免与动作争抢舵机。
- Next:
  - 为 A/B/C 动作补充中间过渡帧，进一步避免卡顿与误碰物体；
  - 实现动作录制与回放（关键帧抽帧 + 定时采样）。

## 2026-10-12 — LiYan1919810 — 运动学解算、直线插值与示教录制

- Done:
  - 程序由 `yaoganmearm/yaoganmearm.ino` 迁移重命名为 `yaogan/yaogan.ino`，代码由 331 行扩展到 1211 行；
  - 完成运动学解算：逆解 `solveIK()` / 关节角换算 `computeJointAngles()` / 正解 `solveFK()`，串口支持 `0`（查询坐标）、`G`（坐标直接逆解）命令；
  - 完成直线插值 `moveLineTo()` / `moveLineTick()`：用「逆解 + 误差累积等比例插值」取代早期逐点推进方案，并加入按径向距离自适应的摩擦力 / 自重误差补偿（`Z_COMP_MM`）；
  - 完成动作帧录制 / 回放 `Frame()` / `Reproduce()`：30ms 采样 + 位移 / 爪子角度阈值抽帧，最多 50 帧，回放逐帧入队；
  - 完成五点示教 `teachRecordPoint()` / `teachPlayStart()` / `teachTick()`：串口 `8` 进入、`7` 退出，播放前回初始位 + 非阻塞等待后逐点走直线；
  - 按键检测改为逐键 `pressed` 事件，扩展按键 2 / 按键 3 在录制播放与示教模式下的功能；重标定舵机行程与初始位，`TURN_INTERVAL` 提速到 15ms。
- Decision:
  - 直线运动改用「误差累积等比例插值」：每个舵机按等比例增量步进、够 ±1° 才转，保证各关节同步到位、轨迹近似直线（早期逐点推进方案只能画出圆弧且抖动，已废弃）；
  - 录制采用「定时采样 + 阈值抽帧」而非定时中断：以爪尖位移（正解）与爪子角度为判据，爪尖未动不浪费帧、爪子开合不丢帧；
  - 示教功能独立于帧录制（串口切换模式），示教点统一锁定首点 z 以保持同一水平面，便于夹笔在纸面画线。
- Next:

  - 结合新运动学能力，为 A/B/C 抓取动作设计更平滑的直线轨迹路径；
