# 机械臂项目开发总结（v0.1.0）

> 本文基于 `开发记录.txt`、`机械臂设计思路.txt` 与当前代码整理，作为项目首个里程碑 **v0.1.0** 的阶段总结。
> 整理时间：2026-09-29

---

## 一、项目概况

本项目基于 **Arduino** 完成机械臂的算法与控制开发，目标分为三条主线：

| 任务 | 内容 | 状态 |
|------|------|------|
| 任务一 | 机械臂基础控制、上位机串口指令交互、多舵机协同控制 | ✅ 已完成 |
| 任务二 | `A` / `B` / `C` 自动夹取任务（需联合机械方向） | 🟡 进行中 |
| 任务三 | 动作录制 / 回放（按键遥控） | 🟡 方案设计中 |

硬件上使用 **4 个舵机**（夹爪 Claw、右侧 Right、左侧 Left、底座 Middle），配合 **双摇杆**、**按键** 进行操控。

### 舵机与引脚对应关系

| 舵机 | 代号 | 引脚 | 说明 |
|------|------|------|------|
| 夹爪 | `C` | 6 | 负责夹爪张开 / 收拢 |
| 右侧 | `R` | 7 | 右臂关节 |
| 左侧 | `L` | 8 | 左臂关节 |
| 底座 | `M` | 9 | 底盘 / 中轴 |

## 二、对外功能实现

### 1. 串口通讯（上位机 → 机械臂）

| 指令 | 功能 |
|------|------|
| `O` | 机械臂爪子张开 |
| `S` | 机械臂爪子关闭 |
| `H` | 提升整体运行速度 |
| `L` | 降低机械臂整体运行速度 |
| `x10,y30,z20` | 解析并同步控制 x / y / z 三个舵机输出对应角度 PWM |
| `A` / `B` / `C` | 自动夹取物体 A / B / C 至对应位置 |

> 实现要点：按键设置、`speed` 控制 `delay`、记录四个舵机的角度状态。

### 2. 按键控制（设计目标）

| 按键 | 功能 |
|------|------|
| 按键一 | 循环触发夹取 A、B、C 物体的动作 |
| 按键二 | 录制按键动作 |
| 按键三 | 播放录制的动作 |
| 按键四 | 机械臂回归初始状态 |
| 按键五 / 六 / 七 | 暂停 / 继续 / 取消 |

## 三、技术要点与关键决策

1. **平滑转向 `turn()`**：封装统一的逐度插值移动函数，只在两端写一次、中间每度 `delay(speed)`，通过 `speed` 变量统一调节整体运行速度——这也是 `H` / `L` 指令的实现基础。

2. **指令解析 `parseAndControl()`**：先按首字符匹配单字符指令（`O`/`S`/`H`/`L`/`A`/`B`/`C`），再对 `x,y,z` 坐标指令用 `strchr` 定位并 `atoi` 取值，最后 `constrain` 到各舵机安全行程范围内，保证指令鲁棒。

3. **非阻塞按键读取**：采用"记录上次读数 → 变化后计时 → 达到去抖阈值 `DEBOUNCE_MS` 才更新稳定状态"的方式（`updateButton()`），避免 `delay()` 阻塞主循环，为后续动作录制 / 回放保留实时性。

4. **摇杆控制**：以 `JOY_CENTER=512` 为 ADC 中点，设置 `JOY_DEADZONE=80` 死区抑制抖动，偏离越大移动越快（`map` 到 1~2 度/周期），并通过 `JOY_INTERVAL` 限速采样周期。

5. **舵机安全行程 protect**：为每个舵机定义 `MAX/MIN pos`，所有写入前统一 `constrain`，防止堵转与机械干涉。

## 四、待解决问题（TODO）

- **任务三：动作录制的中断采样机制**
  - 思路：记录关键帧，采用**抽帧**方式将舵机状态存入二维数组；
  - 难点：**如何在指定秒数后产生一个中断去记录舵机状态**（定时采样方案待确定）。

- **任务二：A/B/C 抓取动作的流畅性**
  - 现状：动作存在**卡顿**、**可能误碰物体**的情况；
  - 方案：**增加中间帧**，让动作更流畅、路线更可控。
